# 처음 30분

## 1. 열기 (5분)

1. Claude Code 로 이 폴더를 엽니다.
   - 데스크톱 앱: 새 세션 → 폴더 선택
   - 터미널: 이 폴더에서 `claude`
2. "이 폴더를 신뢰하시겠습니까" 창에서 허용합니다. gptaku-plugins 마켓과 플러그인 6개가 등록됩니다.
3. 권한 모드는 처음에는 기본(모든 변경을 묻는 모드)으로 둡니다.

## 2. 플러그인 확인과 프로필 (15분)

`/start` 를 입력합니다.

- 플러그인이 보이지 않으면 Claude 가 설치 명령을 알려 줍니다. `/plugin` 명령은 사용자가 직접 입력해야 합니다.
- 내 논문이나 보고서가 있으면 먼저 `00-inbox/` 에 넣으세요. 읽고 질문을 줄여 줍니다.
- 자기 연구 대신 관심 주제로 해 보려면 "관심 주제로 해 볼래"라고 말합니다. 세 가지만 묻습니다.
- 연습만 하려면 "관심 주제 예시로 연습할게"(`examples/연습-관심주제-AI업무/`) 또는 "진동시험 예시로 연습할게"(`examples/가상연구자-진동시험/`)라고 말합니다.
- 외부에 알려지면 안 되는 내용은 답할 때 "비공개"라고 말해 주세요. 검색어로 쓰지 않습니다.

## 3. 첫 시나리오 (10분)

```
/scenario
```

시나리오 3~5개와 비교표가 `20-scenarios/` 에 생깁니다. 마음에 드는 시나리오가 있으면 이어서 `/paper` 나 `/plan` 을 씁니다.

끝낼 때는 `/wrap` 으로 기록을 남깁니다.

## 막힐 때

| 증상 | 할 일 |
|------|-------|
| 플러그인이 목록에 없음 | 폴더 신뢰를 허용했는지 확인 → 안 되면 `/start` 가 안내하는 설치 명령 입력 |
| GitHub 접속이 막힘 | 플러그인 없이 진행. 각 명령이 웹 검색·직접 작성으로 대체 |
| 인용 확인이 `FETCH_FAIL` | 인터넷 연결 확인. 확인 못 한 인용은 "확인 못 함"으로 남음 |
| 프로필을 다시 쓰고 싶음 | `/start` 를 다시 실행하면 바뀐 부분만 고침 |
