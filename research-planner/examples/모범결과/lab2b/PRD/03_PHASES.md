# 주간 논문 수 알리미 -- Phase 분리 계획

> 가정(A1~A8)은 [01_PRD.md](./01_PRD.md) 맨 위 표 참고. 기간은 가정이며 근거 없는 추정입니다.

---

## Phase 1: MVP (⚠️ 가정: 하루~이틀)

### 목표
주제 파일을 넣고 한 번 실행하면 주간 표가 마크다운 파일로 나온다. 예약 실행으로 매주 쌓인다.

### 기능
- [ ] `topics.yaml` 읽기(주제·키워드·제외어)
- [ ] 출처 1곳(가정: OpenAlex)에서 지난 7일 건수 조회
- [ ] SQLite에 주차별 저장(중복 방지, 실패 구분)
- [ ] 마크다운 리포트(이번 주 / 지난 주 / 증감 / 4주 평균)
- [ ] 예약 실행 등록 방법 문서화

### 데이터
- Topic, Keyword, Source, WeeklyCount, Run

### 인증
- 없음(공개 API). 메일 발송은 Phase 2.

### "진짜 제품" 체크리스트
- [ ] 실제 API 호출 (목업 데이터 X)
- [ ] 실제 저장소 파일에 이력이 남음
- [ ] 예약 실행으로 사람 손 없이 한 주가 돌아감
- [ ] 한 주제를 검색 사이트에서 직접 센 값과 대조함

### Phase 1 시작 프롬프트
```
이 PRD를 읽고 Phase 1을 구현해주세요.
@PRD/01_PRD.md
@PRD/02_DATA_MODEL.md
@PRD/04_PROJECT_SPEC.md

Phase 1 범위:
- topics.yaml 읽기, 출처 1곳 건수 조회, SQLite 저장, 마크다운 주간 리포트

반드시 지켜야 할 것:
- 04_PROJECT_SPEC.md의 "절대 하지 마" 목록 준수
- 실제 API 호출 (목업 X). 호출 한도는 먼저 공식 문서로 확인
- 조회 실패를 0건으로 기록하지 말 것
```

## Phase 2: 확장 (⚠️ 가정: 2~3일)

### 전제 조건
- Phase 1이 2주 이상 문제없이 돌았음

### 목표
메일로 받고, 두 번째 출처를 더하고, 대표 논문 링크를 본다.

### 기능
- [ ] 이메일 발송
- [ ] 출처 추가(arXiv) + DOI 기준 중복 제거
- [ ] 주제별 대표 논문 3편(제목·링크)

### 추가 데이터
- Paper

### 통합 테스트
- Phase 1 집계가 그대로 나오는지, 재실행 중복 없음 재확인

---

## Phase 3: 고도화 (⚠️ 가정: 미정)

### 전제 조건
- Phase 1 + 2 안정 운영

### 목표
급증 알림, 연구 기획 워크스페이스와 연결.

### 기능
- [ ] 4주 평균 대비 급증 표시
- [ ] 결과를 `15-market/` 또는 `10-literature/` 문서에 인용할 수 있는 형식으로 내보내기
- [ ] (필요할 때만) 다중 사용자

### 주의사항
- 유료 출처 도입 시 비용·계약 발생. 사용자 확인 후 진행
