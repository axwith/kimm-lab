# Claude Code를 대신하는 모델은 아닙니다

 LLM이 맡는 것 따져 보기 글쓰기, 코드 작성 대화 이어 가기 
 Jev가 맡는 것 답이 정해진 판단 분류, 예/아니오, 점수 그 판단의 확률 

 공식 문서와 LangChain 글 모두 "그대로 갈아 끼우는 대체재가 아니다"라고 씁니다

# 공식 문서가 적어 둔 약점

 한 번 읽고 바로 답해서, 따져 봐야 하는 일에 약합니다 

 코드에 맡길 것 계산과 개수 세기 날짜 비교 점수를 다시 실제 수치로 바꾸기 여러 단계를 이어 가는 추론 
 입력에서 조심할 것 관련 없는 내용이 많은 큰 입력 공격하려고 쓴 글, 서로 모순된 기준 한국어: 영어가 주 학습 언어이고, 한중일 문자는 "다루지만 같은 수준은 아니다"
