## 시나리오 1: 입력 진폭별 감쇠비 변화 — 기존 시험 기록 재분석

### 연구 질문
같은 소형 기기 지지 구조물에서 진동대 입력 레벨(가속도 크기)이 달라질 때 측정되는 공진 주파수와 감쇠비는 어떻게 달라지는가? 내진 시험 합격 판단에 쓰는 응답스펙트럼 비교는 이 변화에 얼마나 민감한가?

### 가설
입력 레벨이 커지면 접합부 미끄럼·마찰 때문에 감쇠비가 커지고 공진 주파수는 낮아질 것이다. 변화가 작다면 낮은 레벨 공진탐색에서 얻은 감쇠비를 그대로 써도 된다. (가설이며 검증 전)

### 방법과 필요한 실험·분석
1. 기존 시험 기록의 메타데이터 점검: 공진탐색(저레벨)과 본 시험(고레벨)이 같은 기기에 대해 모두 있는 건을 추린다.
2. 같은 기기·같은 방향에서 레벨별 전달함수를 구해 반전력 대역폭법과 곡선맞춤으로 감쇠비를 추정한다.
3. 추정법 간 차이를 불확실성으로 함께 보고한다(시나리오 2·4와 연결 가능).
4. 레벨별 감쇠비를 응답스펙트럼 비교에 넣었을 때 합격 여부 판정이 바뀌는지 확인한다.
5. 데이터는 기관 밖으로 나가지 않으므로 분석은 로컬에서만 한다. 외부 AI·검색에는 일반 개념만 쓴다.

### 필요한 자원
| 자원 | 상태 | 증빙 |
|------|------|------|
| 과거 시험 기록 150건 | 보유 | `70-kb/assets/보유역량.md` 내부 데이터 목록 [비공개] (입력 레벨·기기 반복 여부는 미확인) |
| 단축 진동대 | 보유 | 연구실 장비 목록 |
| Python 데이터 후처리 | 부분 | 스크립트는 있으나 문서화·검증 기록 없음 |
| 응답스펙트럼 비교 | 보유 | 학회 발표 2 |
| 추가 시험용 진동대 시간 | 부분 | 월 40시간 안팎(프로필 제약), 필요 시간 미산정 |

### 기대 결과물
- 논문: 국내 학술지 1편 후보 (진동 시험에서 입력 레벨과 감쇠비 관계)
- 데이터: 레벨별 감쇠비 정리표와 후처리 스크립트(문서화·검증 포함)
- 과제: 시험 방법 개선 과제의 예비 결과

### 차별점과 근거
- 확인한 것: 내진 인증 시험에서 공진탐색 입력 레벨이 규정되어 있고, 입력 레벨이 측정 감쇠비에 영향을 줄 수 있다는 설명이 있음. 감쇠비는 반전력법으로 구할 수 있다고 서술됨. 출처: [Zito et al., 2023, CACAIE 시험 프로토콜 논문](https://onlinelibrary.wiley.com/doi/10.1111/mice.12951) (검색 결과 요약 기준, 원문 미열람)
- 직접 같은 시도(소형 기기 지지 구조물의 레벨별 감쇠비 재분석)는 이번 검색(3회)에서 못 찾았으나 "nonlinear damping", "damping versus input level" 검색은 하지 않았다. **차별점 미확인.**

### 위험과 대안
- 기록에 입력 레벨이나 저레벨 공진탐색이 남아 있지 않으면 재분석이 어렵다. → 1주차에 데이터 점검으로 먼저 가부를 판단하고, 안 되면 진동대로 소수 기기만 새로 시험한다(진동대 시간 필요).
- 변화가 없다는 결과가 나와도 "현행 단일 감쇠값 사용이 타당하다"는 근거로 쓸 수 있다.

### 첫 4주에 할 일
1. 1주: 150건의 메타데이터(기기 종류, 방향, 입력 레벨, 공진탐색 유무) 목록 작성.
2. 2주: 짝이 되는 건 추리고, 전달함수 계산 스크립트를 문서화하며 정리.
3. 3주: 반전력법·곡선맞춤 두 방법으로 감쇠비 추정, 방법 간 차이 기록.
4. 4주: 가설 확인 가능 여부 판단과 `/lit` 로 선행연구 보강.

## 시나리오 2: 충격 해머 감쇠비의 불확실성 정량화와 모델 보정 반영

### 연구 질문
충격 해머 시험에서 구한 감쇠비는 시험 반복·충격 위치·창함수에 따라 얼마나 흔들리는가? 그 불확실성을 해석 모델 보정에 반영하면 보정 결과가 달라지는가?

### 가설
감쇠비는 공진 주파수보다 추정 산포가 크므로, 불확실성을 무시하고 점추정만 쓰면 보정된 감쇠 파라미터가 과신될 것이다. (가설이며 검증 전)

### 방법과 필요한 실험·분석
1. 같은 구조물에 반복 충격 시험을 하고 감쇠비 추정값의 분포를 구한다(부트스트랩 등 단순 방법부터).
2. 필요하면 Bayesian 방식으로 사후 분포를 구한다.
3. 보정 단계에서 감쇠 파라미터를 점추정 대신 범위로 넣어 결과를 비교한다.
4. 공개 가능한 연습용 구조물(보 시편 등)로 방법을 먼저 검증하고 기관 데이터에는 로컬에서만 적용한다.

### 필요한 자원
| 자원 | 상태 | 증빙 |
|------|------|------|
| 충격 해머·모달 분석 | 보유 | 학회 발표 1 |
| 상용 모달 분석 소프트웨어 | 보유 | 프로필 기재(별도 증빙 파일 없음 — 확인 필요) |
| Python 데이터 후처리 | 부분 | 문서화·검증 기록 없음 |
| 베이지안·부트스트랩 통계 기법 | 없음 | — (학습 또는 외부 협력 필요) |
| 과거 시험 기록 150건 | 보유 | 내부 데이터 목록 [비공개] |

### 기대 결과물
- 논문: 국내 학술지 후보 → 보강하면 국제 학술지 후보
- 데이터·방법: 감쇠비 불확실성 추정 스크립트와 연습용 검증 사례
- 과제: 모델 보정 자동화 과제의 핵심 요소

### 차별점과 근거
- 확인한 것: 운용 모달 해석(OMA)에서는 Bayesian 방법으로 감쇠비 불확실성을 계산하는 연구가 많고, 감쇠비 추정이 가장 불확실하다는 점이 알려져 있음. [Bayesian OMA 최근 동향 리뷰(Buildings)](https://doi.org/10.3390/buildings16091807), [Hierarchical Bayesian OMA(arXiv 1908.06370)](https://arxiv.org/pdf/1908.06370). 충격 해머 시험과 FE 모델 보정에서 감쇠 추정 불확실성 요인(노화·온도·창함수)을 다룬 연구도 있음: [GFRP 판 모델 보정 연구(ScienceDirect)](https://www.sciencedirect.com/science/article/abs/pii/S0029801824010473).
- 위 자료는 모두 검색 결과 요약만 봤고 원문은 열람하지 않았다. 해머 시험의 전달함수 기반 + 불확실성 반영 보정을 동시에 다룬 선행연구는 찾지 못했으나 **차별점 미확인**(검색 한계).

### 위험과 대안
- 통계 기법 학습 부담이 크다. → 부트스트랩 같은 단순 방법으로 범위를 줄이고, 필요하면 통계 전공자와 협력 가능성을 사람이 판단한다.
- 불확실성이 작게 나오면 새 결과가 되지 않는다. → 이 경우 "시험 절차의 재현성 확인" 자료로 남는다.

### 첫 4주에 할 일
1. 1주: Bayesian OMA 리뷰와 GFRP 판 연구 원문 정독, `/lit` 로 문헌표 작성.
2. 2주: 공개 가능한 시편(보 등)으로 반복 충격 시험 설계.
3. 3주: 부트스트랩으로 감쇠비 분포 추정 스크립트 작성·검증.
4. 4주: 보정 파라미터를 범위로 넣을 때와 점추정일 때 차이 확인 계획 확정.

## 시나리오 3: 온도·노화에 따른 감쇠비 변화

### 연구 질문
온도 변화와 사용 기간(노화)에 따라 지지 구조물의 감쇠비와 공진 주파수가 어떻게 변하는가?

### 가설
온도가 올라가면 감쇠비가 커지고 공진 주파수는 낮아질 것이다. 노화로 접합부 상태가 변하면 감쇠비가 달라질 것이다. (가설이며 검증 전)

### 방법과 필요한 실험·분석
1. 온도 챔버 시험(장비 없음 → 조달 필요).
2. 우회 경로 A: 과거 시험 기록에 실내 온도나 시험 날짜가 남아 있으면 자연 온도 변동과 감쇠비의 상관을 본다(남아 있는지 미확인).
3. 우회 경로 B: 같은 기기를 수년 간격으로 재시험한 기록이 있으면 노화 영향을 본다(있는지 미확인).
4. 챔버 시험은 외부 시험 기관 이용 가능성을 사람이 알아본 뒤 판단한다.

### 필요한 자원
| 자원 | 상태 | 증빙 |
|------|------|------|
| 온도 조건 시험 | 없음 | — |
| 온도 챔버 외부 이용 | 조달 미확보 | 상대 기관·비용 미확인 |
| 충격 해머·모달 분석 | 보유 | 학회 발표 1 |
| 과거 시험 기록 150건 | 보유 | 내부 데이터 목록 [비공개] (온도·재시험 기록 유무 미확인) |

### 기대 결과물
- 논문: 우회 경로가 성립할 때만 후보
- 데이터: 온도·시기별 감쇠비 정리(기록이 있을 때)
- 과제: 장비 확보 계획과 함께 외부 과제 후보

### 차별점과 근거
- 확인한 것: 가열한 알루미늄 판의 열탄성 모달 시험에서 온도가 오르면 주파수는 낮아지고 감쇠는 커졌다는 요약이 있음. [Science.gov 주제 페이지](https://www.science.gov/topicpages/m/modal+damping+ratio.html) (2차 요약, 원 논문 미확인). 이 외 독립 출처는 확보하지 못함.
- 소형 기기 지지 구조물에 대한 온도·노화 연구는 이번 검색에서 직접 찾지 못했으나 "viscoelastic damping temperature modal testing" 등 추가 검색은 하지 않았다. **차별점 미확인.**

### 위험과 대안
- 장비를 못 구하면 핵심 시험을 할 수 없다. 우회 경로 A·B 모두 기록에 정보가 없으면 결과가 남지 않는다. → 1주차 메타데이터 점검(시나리오 1과 같은 작업)으로 가능 여부를 먼저 확인하고, 안 되면 보류.

### 첫 4주에 할 일
1. 1주: 시나리오 1과 같은 메타데이터 목록에 온도·시험 날짜·재시험 여부 열을 추가.
2. 2주: 우회 경로 성립 여부 판단.

## 시나리오 4: 감쇠비 추정 방법 비교 — 반전력법·곡선맞춤·창함수 보정

### 연구 질문
충격 해머 시험 데이터에서 감쇠비 추정 방법마다 편향과 산포가 어떻게 다르고, 시험 조건(샘플링, 창함수, 잡음)에 어떻게 반응하는가?

### 가설
잡음이 커지거나 주파수 해상도가 낮으면 반전력법의 감쇠비가 편향되고, 곡선맞춤 방법은 상대적으로 안정적일 것이다. (가설이며 검증 전)

### 방법과 필요한 실험·분석
1. 감쇠비를 아는 합성 응답에 잡음을 더해 방법별 추정 오차를 비교한다(모두 합성이므로 외부에 공개 가능).
2. 공개 데이터셋 또는 보 시편 시험으로 합성 결과를 확인한다.
3. 결과로 기관 시험의 감쇠비 추정 절차 권장안을 만든다.

### 필요한 자원
| 자원 | 상태 | 증빙 |
|------|------|------|
| Python(numpy, scipy) | 보유 | 프로필 기재(별도 증빙 없음) |
| Python 데이터 후처리 | 부분 | 문서화·검증 기록 없음 |
| 충격 해머·모달 분석 | 보유 | 학회 발표 1 |

### 기대 결과물
- 논문: 방법 비교·시험 절차 제안 논문 후보(국내)
- 데이터·방법: 합성 데이터 생성기와 비교 코드(재현 가능하게 공개 가능)
- 특허·과제: 해당 없음

### 차별점과 근거
- 확인한 것: 지수 창함수가 수치 감쇠를 더해 감쇠 추정을 왜곡하며 이를 보정하는 모델 보정 연구가 이미 있음 [GFRP 판 연구(ScienceDirect)](https://www.sciencedirect.com/science/article/abs/pii/S0029801824010473). 부분적으로 겹치므로 새로움은 낮음.
- 독립 출처 1건만 확보, 같은 비교 연구의 존재 여부는 검색 부족으로 **미확인.**

### 위험과 대안
- 이미 알려진 결과의 재확인에 그칠 수 있다. → 시나리오 1·2의 기반 도구로 쓰면 그 자체로 가치가 있다.

### 첫 4주에 할 일
1. 1주: 합성 응답 생성기와 세 가지 추정 방법 구현.
2. 2주: 잡음·창함수 조건별 오차 비교.
3. 3주: 코드 문서화와 검증 기록 작성(보유역량 표의 "부분" 해소).
4. 4주: `/lit` 로 방법 비교 선행연구 보강.

## 미확인

- 새로움 점수는 모두 비웠다. 선행연구 검색은 3회뿐이고 원문은 열람하지 않았다(`/lit` 필요).
- 150건의 기록에 입력 레벨, 공진탐색 유무, 온도, 재시험 여부가 있는지 (시나리오 1·3의 가능 여부를 가름).
- 상용 모달 분석 소프트웨어와 Python 환경의 증빙 파일이 `70-kb/assets/` 에 없음.
- 온도 챔버를 외부에서 이용할 수 있는지, 비용과 상대 기관.
- 통계 기법(Bayesian) 학습이나 협력을 연구실에서 감당할 수 있는지.
- 어떤 시나리오를 택할지, 목표 학술지, 저자 구성: 연구자가 정한다.
