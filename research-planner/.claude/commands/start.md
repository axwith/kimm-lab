# /start — 플러그인 확인과 연구 프로필

이 공간을 처음 열었을 때 한 번 합니다. 프로필이 이미 있으면 바뀐 부분만 고칩니다.

## Step 1: 플러그인 확인

이 폴더를 처음 열 때 나온 "이 폴더를 신뢰하시겠습니까" 창에서 허용했다면 gptaku-plugins 마켓과 플러그인 6개가 자동으로 등록됩니다(`.claude/settings.json`).

1. 사용자에게 `/plugin`(데스크톱 앱은 입력창의 `+` → Plugins)에서 아래 6개가 켜져 있는지 확인해 달라고 합니다.
   docs-guide, insane-research, insane-search, show-me-the-prd, skillers-suda, kkirikkiri
2. 보이지 않으면 아래 명령을 안내합니다. 사용자가 직접 입력해야 합니다.
   ```
   /plugin marketplace add https://github.com/fivetaku/gptaku_plugins.git
   /plugin install docs-guide@gptaku-plugins
   ```
   나머지 플러그인도 이름만 바꿔 같은 방식으로 설치합니다.
3. GitHub 접속이 막힌 환경이면 플러그인 없이 진행합니다. 각 명령은 플러그인이 없을 때의 대체 방법(웹 검색, 직접 작성)을 갖고 있습니다.

## Step 2: 가진 자료 읽기

`00-inbox/` 에 파일이 있으면 먼저 읽습니다(내 논문, 보고서, 발표 자료, 메모). 읽은 내용으로 Step 3 질문의 답을 미리 채우고, 사용자에게는 확인만 받습니다.

`examples/` 의 가상 프로필로 연습하는 경우에는 그 파일을 `70-kb/profile/연구프로필.md` 로, 같은 폴더의 `보유역량.md` 를 `70-kb/assets/보유역량.md` 로 복사하고 Step 4로 갑니다.
- 자기 연구 예시: `examples/가상연구자-진동시험/`
- 관심 주제 예시: `examples/연습-관심주제-AI업무/`

### 관심 주제로 빠르게 시작

사용자가 "내 연구 말고 관심 주제로 해 볼래"라고 하면 Step 3 인터뷰 대신 세 가지만 묻습니다.
1. 관심 주제 한 문장
2. 왜 궁금한가(업무에서 겪은 일, 뉴스, 호기심)
3. 끝나면 무엇을 갖고 싶은가(논문 동향 한 장, 과제 아이디어, 시장 판단)

답으로 프로필을 채우고, 나머지 절은 "미확인"으로 둡니다.

## Step 3: 인터뷰

한 번에 한 질문만 합니다. 답이 짧으면 예를 들어 다시 묻되, 대신 지어내지 않습니다.

1. 연구 분야와 소속 유형(대학, 출연연, 기업 연구소 등)
2. 지금 하고 있는 연구 한두 개: 무엇을, 어떤 방법으로, 어디까지 했는지
3. 쓰는 장비, 소프트웨어, 데이터(종류와 규모)
4. 지금까지의 성과: 논문, 특허, 보고서, 데이터셋(공개된 것은 링크나 DOI)
5. 앞으로 1~2년의 목표: 논문(분야·학회·저널), 과제, 기술
6. 제약: 인력, 예산, 장비 사용 시간, 보안 규정
7. 관심은 있는데 아직 못 한 주제
8. 이 내용 가운데 외부에 알려지면 안 되는 것 → `[비공개]` 표시

## Step 4: 저장

- `70-kb/profile/연구프로필.md` — 아래 절을 모두 둡니다. 답이 없는 절은 "미확인"으로 둡니다.
  `## 분야` `## 현재 연구` `## 방법·장비·데이터` `## 성과` `## 목표` `## 제약` `## 관심 주제` `## 비공개 항목`
- `70-kb/assets/보유역량.md` — 장비, 데이터, 기술, 성과를 표로 정리하고 열마다 증빙 위치(DOI, 파일 경로, 보고서 번호)를 적습니다. 증빙이 없는 행은 상태를 "부분"으로 둡니다.

저장한 뒤 `python3 60-scripts/check_planner.py 70-kb/profile/연구프로필.md` 를 돌립니다.

## Step 5: 다음 할 일 제안

프로필을 보고 다음 중 하나를 권합니다.
- 관심 주제의 최근 연구를 모르면 → `/lit {질문}`
- 방향을 넓히고 싶으면 → `/scenario`
- 이미 쓸 논문이 정해졌으면 → `/paper {주제}`
- 과제 공고를 찾고 있으면 → `/grant search {키워드}`
