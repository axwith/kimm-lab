# /market — 시장·수요 조사

```text
/market {주제}            # 주제 하나의 수요, 시장, 경쟁 정리
/market compare {파일}    # 시나리오 파일의 후보마다 수요 한 줄씩 붙이기
```

이 명령은 주제를 누가 필요로 하는지, 누가 돈을 쓰는지, 이미 무엇이 팔리는지 찾습니다. 결과는 `/scenario` 의 `수요` 기준 근거로 씁니다.

## Step 1: 질문 정하기

검색 전에 아래를 정하고 사용자에게 한 번 확인받습니다.
- 주제를 한 문장으로(예: "AI 에이전트로 연구자의 문서 업무 줄이기")
- 보고 싶은 쪽: 쓰는 사람(수요자), 파는 회사(공급자), 돈을 대는 곳(정부·기관)
- 지역(기본 국내 + 세계), 기간(기본 최근 3년)
- 프로필의 `[비공개]` 항목은 검색어에 넣지 않습니다.

## Step 2: 찾기

insane-research 가 켜져 있으면 공개 주제로 조사를 맡기고, 없으면 웹 검색으로 같은 일을 합니다. 막힌 페이지는 insane-search 로 읽습니다. 아래 다섯 가지를 찾습니다.

1. 수요자: 누가 어떤 불편을 겪나(설문, 기사, 기관 보고서)
2. 시장 규모: 조사기관 수치가 있으면 기관명, 연도, 범위를 그대로 적습니다. 기관마다 정의가 다르니 숫자를 섞어 평균 내지 않습니다.
3. 정책·예산: 정부 계획, 공고, 예산 항목(`/grant search` 로 이어질 키워드를 같이 적습니다)
4. 기업·제품: 이미 파는 것, 가격대, 사용 사례
5. 반대 신호: 실패 사례, 규제, 사람들이 쓰지 않는 이유

## Step 3: 저장

`15-market/{YYYY-MM-DD}-{주제}.md` 에 아래 절을 둡니다.

```
## 한 줄 결론            (수요가 있다 / 아직 이르다 / 판단 근거 부족 중 하나와 이유)
## 수요자와 불편
## 시장 규모              (표: 출처 | 연도 | 범위 정의 | 수치 — 원문 수치만)
## 정책·예산
## 기업·제품              (표: 이름 | 하는 일 | 출처)
## 반대 신호
## 연구 주제로 이어지는 빈틈
## 미확인
```

## 지킬 것

- 수치는 원문에 있는 것만 쓰고 출처를 붙입니다. 출처가 광고성 보도자료이면 그렇다고 적습니다.
- "유망하다", "성장이 기대된다" 같은 말은 근거 수치나 사례 없이 쓰지 않습니다.
- 회사·제품을 추천하지 않습니다. 있는 것을 나열만 합니다.

## Step 4: 확인과 다음 단계

```bash
python3 60-scripts/check_planner.py 15-market/{파일}.md
python3 60-scripts/cite_check.py file 15-market/{파일}.md
```

다음 단계로 `/scenario {주제}` 를 권합니다. 시나리오의 `수요` 점수는 이 파일을 근거로 매깁니다.
