# /kb — 내 연구 지식베이스

같은 자료를 매번 다시 설명하지 않으려고 쌓는 층입니다. `/grant fit`, `/scenario`, `/paper`, `/plan` 이 모두 여기를 먼저 읽습니다. research-lab `/kb` 를 연구 기획용으로 옮긴 것입니다.

```text
/kb ingest          # 00-inbox 흡수 → 70-kb 등재, 원본은 00-inbox/_done 으로
/kb {질문}          # 조회 ("내 측정 관련 실적", "내가 쓰던 분석 방법")
/kb gaps            # 비어 있는 칸 보고
/kb check           # 중복·낡은 정보·증빙 없는 "보유" 점검 (한 달에 한 번)
```

## 어디에 무엇을 쌓나

| 폴더 | 담는 것 |
|---|---|
| `70-kb/sources/` | 자료 하나당 요약 카드 한 장 |
| `70-kb/assets/` | 실적·장비·데이터·기술. **증빙이 있어야 "보유"** |
| `70-kb/style/` | 문서 스타일, 문서 구성, 용어집 |
| `70-kb/profile/` | 연구 프로필 |
| `70-kb/outcomes/` | 지원 이력과 결과, 심사 의견(가장 값진 자료) |
| `70-kb/requirements/` `programs/` `agencies/` | 공고 요건 패턴, 사업, 전문기관 성향 |

## `/kb ingest`

### Step 1: 분류

`00-inbox/` 의 파일을 먼저 종류별로 나눕니다(읽기 전에 분류).

| 종류 | 가는 곳 |
|---|---|
| 내가 쓴 논문·학회 발표 | `sources` 카드 + `assets` 실적 행 + `style` 근거 |
| 보고서·결과보고서 | `sources` + `style`(문서 구성 순서) |
| 과제 계획서·결과 | `assets` + `outcomes` |
| 평가 결과·심사 의견 | `outcomes` 최우선 |
| 공고문 | `requirements` |
| 메모·캡처 | `sources`, 출처를 "내부 메모"로 |

- HWP는 PDF로 저장해서 다시 넣어 달라고 안내합니다. 변환 도구(`npx -y kordoc`)는 Node.js가 있을 때만 씁니다.
- 강의 실습 중(`.lab-progress.json` 이 있고 lab2 가 진행 중)에는 10개를 넘으면 최근 것 10개만 먼저 하자고 안내합니다. 강의 뒤에는 `KB-구축가이드.md` 대로 한 묶음 10~20개까지 받습니다.

### Step 2: 요약 카드 — 원문을 복사하지 않습니다

`70-kb/sources/{YYYY-MM-DD}-{짧은이름}.md`

```markdown
# {제목}
- 종류: 논문 / 발표 / 보고서 / 메모
- 연도, 저자(내 역할):
- 원본: 00-inbox/_done/{파일명}  (공개 자료면 DOI·주소도)
- 확인일:
## 요지 (3줄)
## 방법·도구·데이터
## 결과·수치 (원문 그대로, 쪽수)
## 스타일 메모 (문장 끝맺음, 구성 순서, 표·그림 습관)
## 미확인
```

- 사실, 출처, 확인일로 적습니다. 추정은 `(미확인)` 으로 구분합니다.
- 개인정보·계좌·주민번호는 적지 않습니다. 발견하면 요약도 남기지 않고 알립니다.

### Step 3: 등재

- `assets/보유역량.md` 에 행을 추가합니다. 증빙 열이 비면 상태는 "부분"입니다.
- `style/작업스타일.md`, `style/용어집.md` 에 자료에서 보인 습관을 덧붙입니다. 자료 두 개 이상에서 보인 것만 "습관"으로 씁니다.
- 원본은 `00-inbox/_done/` 으로 옮깁니다.
- `70-kb/INDEX.md` 에 한 줄씩 적습니다.

### Step 4: 보고

무엇을 어디에 등재했는지 표로 보여 주고, 마지막에 `/kb gaps` 결과 세 줄을 붙입니다.

## `/kb {질문}`

`INDEX.md` → 해당 카드 순서로 읽고, 답마다 카드 경로와 원본 위치를 붙입니다. KB에 없으면 "KB에 없음"이라고 하고 웹을 찾지 않습니다(웹은 `/lit`).

## 강의 뒤에 KB를 키우는 법

`KB-구축가이드.md` 를 따릅니다.
