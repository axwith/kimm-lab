## 사용법

```text
/proposal story              # P4 — 스토리라인 (계획서 전에 반드시)
/proposal A                  # Phase A — 1장(1-1~1-3) + 2-1 최종목표
/proposal B                  # Phase B — 2-2~2-3 + 3장(3-1~3-5) + 예산·KPI
/proposal C                  # Phase C — 4장(4-1~4-3) + 5장(5-1~5-5) + 6~8장
/proposal merge              # 병합 + 정합성 대조
/proposal check              # 게이트 점검만
```

> ⚠️ **목차는 공고 양식이 정본이다.** 아래 구조는 2026 에너지수요관리사업 양식(실측)이며

### B-2: 사업비 계획 ★ (2026-08-03 신설)

**공고에 총 사업비와 연구비 한도가 명시돼 있으면 예산 계획은 선택이 아니라 필수 서식이다.** 없으면 서식 미비로 탈락한다.

세부 계상 기준(간접비 비율·연구수당 한도·장비비 제한)은 **공고 붙임의 사업비 산정 기준표에 적혀 있다.** 추론하지 말고 그 문서를 읽는다.

| 항목 | 산정 근거 | 주의 |
|------|----------|------|
| 인건비 | 참여연구원 × 참여율 × 기간 | 참여율 합이 100% 초과 불가 |
| 연구시설·장비비 | 신규 구입 / 기존 활용 구분 | 한도·사전승인 요건 확인 |
| 연구재료비 | 2-3 과업에서 역산 | |

> - [ ] **★ 인건비 단가 검산 통과** (아래)

#### 인건비 단가 검산 ★ (2026-08-03 신설 — 필수)

**합계가 맞는다고 예산이 맞는 게 아니다.** 참여율 표와 인건비 총액은 **따로 만들어지므로 서로 모순될 수 있고, 총액 검증은 이걸 못 잡는다.**

```
① 참여율 합계(FTE)  = Σ(인원 × 참여율)
② 투입 인월          = ① × 연구기간(개월)
③ 1인월당 단가       = 계상 인건비 ÷ ②
④ 판정: ③이 직급 구성에 맞는 통상 단가 구간 안인가?
```

**통상 계상 단가 참고** (출연연 기준, 4대보험 포함 월액)

| 직급 | 구간(천원/월) |
|------|-------------:|
| 책임급 | 8,000~10,000 |
| 선임급 | 6,000~8,000 |
| 원급 | 4,500~6,000 |

- ③이 구간을 **밑돌면** → 참여율이 과다하다. **인원·참여율을 줄인다** (예산은 공고가 고정하므로 조정 대상은 투입 규모다)
- ③이 구간을 **웃돌면** → 참여율이 과소하거나 인건비가 과다하다
- **편성도 표에 `월 인건비`·`계상액` 열을 반드시 둔다.** 참여율만 있는 표는 검산이 불가능하다

> **실측 근거**: 2026-08-03 데모에서 2.1 FTE × 8개월 = 16.8인월에 42,000천원을 계상해
> **1인월 250만원**(출연연 단가의 1/3)이 나왔다. 총액 게이트는 "70,000천원 일치 ✅"로 통과시켰다.
> research-lab 저장소의 2026-08-03 데모 검토 기록 D2

## `/proposal merge` — 병합과 정합성 대조

A·B·C를 목차 순서로 합치고 **문서 간 불일치를 잡는다.** `contradiction-finder`에 위임한다.

대조 항목:
- 2-1 최종목표 ↔ 2-2 연차목표 합 ↔ 4-2 기대효과 — **숫자가 일관되는가**
- 2-3 연구내용 ↔ 2-4 일정 — **모든 과업에 일정이 있는가**
- 3-2 추진체계 ↔ 5-1 사업화 — **주체가 일관되는가**
