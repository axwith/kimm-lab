# /plan — 연구 기획서

```text
/plan {시나리오 파일 또는 주제}
```

## Step 0: 읽기

프로필, 보유역량, 해당 시나리오, 문헌표를 읽습니다.

## Step 1: 기획서 작성

`40-plans/{YYYY-MM-DD}-{주제}.md` 에 `frameworks/research-plan.md` 의 절을 모두 씁니다.

- 최종 목표와 단계별 목표
- 단계별 연구 내용과 방법(분기 또는 연차)
- 자원 대조표: 자원 | 상태(보유/부분/조달 가능/조달 미확보/없음) | 증빙 | 메울 방법
- 인력과 역할
- 예산 항목: 비목과 산정 근거만 적고, 금액은 연구자가 넣습니다. 금액을 넣었다면 `check-submission.py` 로 합계를 확인합니다
- 위험과 대응
- 성과 지표: 논문, 특허, 데이터, 시제품 — 개수와 시점
- 일정표
- 연결할 수 있는 과제: `/grant search` 로 찾을 키워드

## Step 2: 연구용 도구가 필요할 때

데이터 처리 프로그램, 실험 관리 도구처럼 직접 만들 소프트웨어가 계획에 있으면 show-me-the-prd 로 기획 문서를 따로 만들고 `40-plans/{주제}-tool/` 에 둡니다.

## Step 3: 확인

```bash
python3 60-scripts/check_planner.py 40-plans/{파일}.md
```

"없음"이나 "조달 미확보"가 핵심 자원에 있으면 기획서 맨 위에 먼저 적습니다. 그 상태로 진행할지는 연구자가 정합니다.
