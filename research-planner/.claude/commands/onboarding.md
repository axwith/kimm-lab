# /onboarding — 내 연구 워크스페이스 세팅

research-lab 온보딩(내 자료로 채우기, 증빙 원칙)과 workmate 온보딩(인터뷰 → 자료 → "이렇게 이해했어요" → 반영)을 합친 절차입니다. 한 번에 한 단계씩 진행하고, 각 단계가 끝나면 `70-kb/profile/onboarding-state.md` 에 어디까지 했는지 적어 중간에 끊겨도 이어서 합니다.

## 지킬 것

- **선택지가 있는 질문은 AskUserQuestion 도구로** 묻습니다(번호를 글로 치게 하지 않습니다). 한 번에 최대 4문항까지 묶을 수 있습니다. 말로 설명해야 하는 질문은 한 번에 하나씩 글로 받습니다. AskUserQuestion을 쓸 수 없는 환경이면 번호 목록으로 묻습니다.
- **답을 지어내지 않습니다.** 모르면 "미확인"으로 둡니다. 예시를 들어 다시 물을 수는 있습니다.
- **공개해도 되는 내용만 받습니다.** 기관 과제명, 미공개 데이터, 장비 정보, 협력사 이름은 받지 않고, 답에 섞여 있으면 `[비공개]` 로 바꿔 적습니다. 이 워크스페이스가 읽은 내용은 처리를 위해 Anthropic 서버로 전송됩니다.
- 강사 따라 하기(`examples/강사-따라하기/`)로 하는 경우에는 그 폴더의 `인터뷰답.md` 를 답으로 씁니다. 8문항과 답을 표 하나로 보여 주고 넘어갑니다.
- **`examples/모범결과/` 는 읽지도 복사하지도 않습니다.** 강사 따라 하기도 3단계 흡수(`/kb ingest`)를 실제로 실행해 카드·보유역량·스타일을 새로 만듭니다. 모범 결과는 실습이 끝난 뒤 비교용입니다.

## 0. 상태 확인

`70-kb/profile/onboarding-state.md` 를 읽습니다.
- 없음 → 1단계부터.
- 중간에 멈춤 → "N단계에서 멈췄습니다. 이어서 할까요?" 하고 이어 갑니다.
- 완료 → "이미 끝났습니다. 바꿀 부분만 고칠까요?" 하고 바뀐 것만 받습니다.

## 0-1. 전체 보기 (처음 시작할 때 한 번 출력)

```
온보딩 — 이 워크스페이스를 내 것으로 세팅합니다

1. 인터뷰 — 선택 질문 4개, 짧은 글 질문 4개
2. 자료 넣기 — 00-inbox 에 최근 공개 자료 10개 이내
3. 자료 흡수 — 자료마다 요약 카드, 스타일, 실적 정리
4. 확인 — "이렇게 이해했어요"를 읽고 틀린 곳 고치기
5. 반영 — 연구프로필·작업스타일·용어집·CLAUDE.md "나에 대해"
6. 마무리 — 새 세션에서 반영 확인
```

## 1. 인터뷰 — 나는 누구이고 어떻게 일하나

선택 질문 1·3·5·6을 **AskUserQuestion 한 번**에 묶어 묻습니다(5번은 여러 개 고르기). 그다음 글 질문 2·4·7·8을 하나씩 묻습니다.

1. 소속 유형: 1) 출연연·국공립 연구기관 2) 대학 3) 기업 연구소 4) 그 밖
2. 분야와 하는 일 한 줄(예: "기계 구조물 시험과 데이터 분석", "로봇 제어 알고리즘 연구")
3. 역할: 1) 연구 책임·기획 2) 연구 수행 3) 시험·분석 4) 연구 관리·행정
4. 매주 반복하는데 가장 시간이 오래 걸리는 일 한두 개
5. 주로 쓰는 문서: 1) 논문 2) 연구·결과 보고서 3) 시험 성적서·절차서 4) 과제 계획서 (여러 개 가능)
6. 답변 방식: 1) 결론 먼저, 표·숫자 위주 2) 근거와 함께 자세히 3) 짧게 핵심만
7. "이렇게는 하지 마라"는 것(없으면 없음)
8. 요즘 관심 있는 주제나 다음에 해 보고 싶은 연구 한 줄

## 2. 자료 넣기 — 대기 단계

아래를 안내하고 사용자가 "완료"라고 할 때까지 기다립니다.

```
00-inbox 폴더에 내 자료를 넣어 주세요. 오늘은 최근 것 10개 이내만 넣습니다.
- 넣을 것: 내가 쓴 논문, 학회 발표, 공개된 보고서, 공개된 과제 요약
- HWP 파일은 PDF로 저장해서 넣습니다
- 넣지 않는 것: 기관 내부 문서, 미공개 데이터, 개인정보가 든 파일
```

안내 뒤 AskUserQuestion으로 기다립니다: header `자료`, question "자료를 다 넣었나요?" — "다 넣었어요"(3단계로) / "자료 없이 진행"(3단계를 건너뛰고 인터뷰만으로 4단계). 참가자가 글로 "완료"·"건너뛰기"라고 해도 같은 뜻으로 받습니다.

강사 따라 하기는 `examples/강사-따라하기/inbox/` 의 파일을 `00-inbox/` 로 복사하고 바로 다음으로 갑니다.

## 3. 자료 흡수 — `/kb ingest`

`.claude/commands/kb.md` 의 `ingest` 절차를 그대로 실행합니다. 끝나면 무엇을 어디에 등재했는지 표로 보여 줍니다.

## 4. "이렇게 이해했어요" — 확인 단계

인터뷰 답과 흡수한 자료를 합쳐 아래 형식으로 보여 주고 맞는지 묻습니다.

```
이렇게 이해했습니다.
- 하는 일:
- 자주 쓰는 방법·도구:
- 문서 스타일: (문장 끝맺음, 문서 구성 순서, 표·그림 쓰는 방식, 단위·용어 습관)
- 자주 쓰는 용어 5개:
- 증빙이 있는 실적: (자료 이름과 함께)
- 먼저 시켜 볼 만한 일 3가지:
```

보여 준 뒤 AskUserQuestion으로 묻습니다: header `확인`, question "이렇게 이해한 것이 맞나요?" — "맞아요, 반영해 주세요" / "고칠 곳이 있어요". 고칠 곳이 있으면 무엇이 틀렸는지 글로 받아 고쳐서 다시 보여 줍니다. 자료에서 찾지 못한 항목은 "자료에 없음"으로 씁니다.

## 5. 반영 — 파일 쓰기

확인이 끝나면 아래를 씁니다. 쓰기 전에 무엇을 쓸지 목록으로 한 번 보여 줍니다.

| 파일 | 내용 |
|---|---|
| `70-kb/profile/연구프로필.md` | `## 분야` `## 현재 연구` `## 방법·장비·데이터` `## 성과` `## 목표` `## 제약` `## 관심 주제` `## 비공개 항목` |
| `70-kb/style/작업스타일.md` | 문서 스타일, 문서 구성 순서, 답변 방식, 금지 사항 |
| `70-kb/style/용어집.md` | 자료에서 뽑은 용어와 뜻, 단위 표기 |
| `70-kb/assets/보유역량.md` | 실적·역량 표. 열마다 증빙 위치. 증빙 없는 행은 "부분" |
| `CLAUDE.md` 맨 아래 `## 나에 대해` | 한 줄 소개, 답변 방식, 금지 사항, "문서는 70-kb/style 을 따른다", 관심 주제 |

`CLAUDE.md` 의 다른 절은 고치지 않습니다. `## 나에 대해` 가 이미 있으면 그 절만 바꿉니다.

## 6. 마무리

- `python 60-scripts/check_planner.py 70-kb/profile/연구프로필.md` 를 돌립니다(macOS·Linux는 `python3`).
- 상태 파일에 "완료"와 날짜를 적습니다.
- 다음을 안내합니다: "새 세션을 열어 '나에 대해 아는 것을 말해 줘'라고 해 보세요. 오늘 정한 내용이 반영됐는지 확인합니다." 그리고 4단계의 "먼저 시켜 볼 만한 일" 가운데 하나를 실습 3 주제로 권합니다.
