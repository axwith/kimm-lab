# /wrap — 세션 기록

`90-log/{YYYY-MM-DD}.md` 에 아래를 씁니다. 같은 날 파일이 있으면 아래에 덧붙입니다.

- 오늘 한 일
- 만들거나 고친 파일(경로)
- 연구자가 정한 것
- 아직 확인하지 못한 것(각 문서의 `## 미확인` 에서 모음)
- 다음에 할 일 하나

프로필이나 보유역량이 바뀌었으면 `70-kb/profile/`, `70-kb/assets/` 도 고칩니다. 공고 판정을 했으면 `python 60-scripts/ancm_state.py mark ...`(macOS는 `python3`)로 기록했는지 확인합니다.

## 대기열 처리 (교육 배포본)

세션이 끝날 때 훅(`session_end_queue.py`)이 `90-log/_queue/` 에 도구 이력을 남깁니다. `/wrap` 은 오늘 대화를 기록한 뒤 대기열도 처리합니다.

0. 파일 목록과 내용은 Read 도구나 읽기 전용 명령(`ls`·`find`, PowerShell `Get-ChildItem`)으로 봅니다. 옮기기·지우기 명령은 쓰지 않습니다.
1. `90-log/_queue/*.jsonl` 가운데 `90-log/_queue/처리함.txt` 에 이름이 없는 것만 오래된 것부터 읽습니다. 첫 줄은 세션 정보, 나머지는 도구 이력입니다.
2. 세션마다 "한 일·만들거나 고친 파일·실패한 것"을 이력에서 뽑아 해당 날짜의 `90-log/{YYYY-MM-DD}.md` 에 `### 세션 {id} (자동 기록)` 으로 덧붙입니다. 대화 내용은 이력에 없으므로 "연구자가 정한 것"은 "기록 없음"으로 둡니다.
3. 처리한 파일 이름을 `90-log/_queue/처리함.txt` 에 한 줄씩 덧붙입니다(없으면 만듭니다). 파일을 옮기거나 지우지 않습니다 — 파일 편집만 하면 승인 창 없이 끝납니다(`settings.json` 이 `90-log/` 편집을 허용).
4. 예약 실행(`claude -p "/wrap"`)으로 돌 때는 대화가 없으므로 2~3만 합니다.
