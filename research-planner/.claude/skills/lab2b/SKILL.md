# /lab2b — 실습 2-B · 오전에 본 플러그인 써 보기 (선택)

공통 규칙: `.claude/skills/_공통규칙.md` (흐름·막힐 때·정리 방식)

## 전체 보기 (맨 먼저 그대로 출력)

```
실습 2-B — 오전에 본 플러그인 써 보기 (선택 실습)

목표: 플러그인 이름을 외우는 게 아니라, 플러그인이 남긴 파일과 근거를 확인합니다.

1. docs-guide — 공식 문서를 확인하고, 실습 1 그래프를 한글 제목으로 다시 그립니다 (5단계: 개선하기)
2. show-me-the-prd — "매주 논문 수를 받아 보는 도구"의 기획 문서를 만듭니다 (5단계: 기획하기)
3. 결과 폴더 확인 — 두 플러그인이 남긴 파일과 근거를 봅니다 (5단계: 검토하기)

끝나면 남는 것: 10-literature/ 의 한글 그래프와 문서 주소, PRD/ 기획 문서 네 개
```

## 선택 (AskUserQuestion)

- header `범위`, question "어디까지 해 볼까요?"
  - "둘 다" — docs-guide 다음 show-me-the-prd
  - "docs-guide만" — 시간이 빠듯할 때
  - "show-me-the-prd만" — 그래프는 실습 1에서 충분히 봤을 때
  - "건너뛰기" — 아무것도 실행하지 않고 /lab3 안내만

고른 것만 진행 안내에 넣습니다.
