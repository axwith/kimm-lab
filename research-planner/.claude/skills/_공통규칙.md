# 실습 스킬 공통 규칙 (lab2~lab4, fastcampus-cc part 스킬 방식)

## 흐름

전체 보기 → 선택(AskUserQuestion) → 자동 셋업 → 브리핑 + 진행 안내(한 메시지) → 참가자가 STEP 1~5 진행(스킬은 끼어들지 않음) → "완료"·"/wrap"·"끝" → 정리(WRAP).

- **전체 보기**: 스킬을 부르면 맨 먼저 각 스킬의 "전체 보기" 블록을 그대로 보여 줍니다. 이번 실습의 목표, STEP 1~5가 각각 무엇인지, 끝나면 남는 파일을 먼저 알고 시작하게 하려는 것입니다. 이때는 아무것도 실행하지 않습니다. 새 세션 규칙(대기열·최근 기록 확인)을 먼저 했더라도 **전체 보기 블록이 첫 응답의 맨 앞**에 와야 하고, 그 확인 결과는 전체 보기 아래 한 줄로만 씁니다.
- **선택**: 전체 보기 바로 뒤에 각 스킬의 "선택" 절 질문을 **AskUserQuestion 도구로** 묻습니다(번호를 글로 치게 하지 않습니다). 답을 받은 뒤에만 자동 셋업으로 갑니다. AskUserQuestion을 쓸 수 없는 환경이면 같은 선택지를 번호 목록으로 보여 줍니다.
- **자동 셋업**: 스킬이 직접 실행합니다. 그 실습에 필요한 자료(예시 자료, 앞 실습 결과)를 가져다 두고, 결과를 한 줄로 보고합니다. 참가자에게 폴더 만들기·복사 명령을 치라고 하지 않습니다. 셋업이 실패해도 진행 안내는 출력하고 실패 항목에 "확인 필요"를 붙입니다.
- **브리핑 + 진행 안내**: 각 스킬의 "브리핑"(한 줄 정의 표, 동작 흐름, 핵심 메시지)과 "진행 안내"(STEP별 보낼 요청문, 나오는 것, 확인할 것)를 한 메시지로 출력합니다. 요청문은 코드 블록에 넣어 그대로 복사해 보낼 수 있게 합니다.

## 진행 중

- 참가자가 "막혔어요", "도와줘"라고 할 때만 각 스킬의 "막히면" 표에서 맞는 줄을 골라 짧게 돕습니다. 답을 대신 다 해 주지 않습니다.
- "STEP N 다시", "STEP N 요청문"이라고 하면 그 STEP 블록만 다시 보여 줍니다.
- "모범 결과 보여 줘", "강사 결과"라고 하면 각 스킬의 "모범 결과" 경로의 파일을 읽어 핵심만 보여 줍니다. 모범 결과는 강사가 사전 실행한 결과이며 참가자의 답과 같을 필요는 없다고 덧붙입니다. **모범 결과를 복사해 참가자의 결과로 만들지 않습니다.** 실습은 트랙 1(강사 따라 하기)도 실제로 실행하고, 모범 결과는 끝난 뒤 비교할 때나 "막히면" 표가 대체로 지정한 경우에만 읽습니다.
- 진행 중 확인이 필요한 갈림길(자료를 다 넣었는지, 이해한 내용이 맞는지 등)도 AskUserQuestion으로 묻습니다. 회고처럼 자유롭게 말해야 하는 답은 글로 받습니다.

## 정리 (WRAP)

1. **회고를 먼저 묻습니다**: "가장 쓸모 있었던 것 한 줄 적어 주세요". 답을 받은 뒤에 기록을 씁니다(빈 칸으로 쓰지 않습니다). "완료"와 함께 회고를 줬으면 그것을 씁니다.
2. 기대 파일이 있는지 확인합니다. 없으면 "미생성"으로 적고 어느 STEP을 다시 하면 되는지 알려 줍니다.
3. 각 스킬의 기록 양식대로 `90-log/실습/labN.md` 를 씁니다. 완료는 `YYYY-MM-DD HH:MM` 형식입니다.
4. `.lab-progress.json` 의 `done` 에 추가하고 `last_activity` 에 같은 시각을 적습니다.
5. 다음 실습을 안내합니다.

## 그 밖

- STEP 1~5는 5단계(1 질문하기, 2 기획하기, 3 만들기, 4 검토하기, 5 개선하기)에 맞춰 붙입니다.
- 명령은 지금 쓰는 셸에 맞게 씁니다. Windows는 보통 PowerShell(`Copy-Item`, `New-Item -ItemType Directory -Force`), Git Bash와 macOS는 bash(`cp`, `mkdir -p`). 파이썬은 Windows `python`(없으면 `py`), macOS `python3`. 파일이 있는지 보는 것은 Read 도구나 읽기 전용 명령(`ls`·`find`, PowerShell `Get-ChildItem`)으로 합니다.
- 넣는 자료와 요청문에는 공개해도 되는 내용만 씁니다. 기관 과제명·미공개 데이터·장비 정보는 넣지 않습니다.
- AskUserQuestion 선택지는 2~4개, 라벨 40자·설명 60자 이내, 이모지 없이 씁니다. 자유 입력은 도구가 "Other"로 자동 제공하므로 따로 넣지 않습니다.
