# 연구 기획서 기준

> `/plan` 에서 호출합니다. 공고에 내는 계획서는 `rnd-proposal-pipeline.md` 를 따르고, 이 기준은 그 전에 연구 자체를 기획할 때 씁니다.

## 필수 절

| 절 | 들어갈 것 |
|----|-----------|
| `## 목표` | 최종 목표 한 문장, 단계별 목표 |
| `## 단계별 내용과 방법` | 분기 또는 연차별로 무엇을 어떻게 |
| `## 자원 대조표` | 자원, 상태, 증빙, 메울 방법 (상태 정의는 `rfp-fit-matrix.md`) |
| `## 인력과 역할` | 누가 무엇을, 필요한 추가 인력 |
| `## 예산 항목` | 비목과 산정 근거. 금액은 연구자가 넣음 |
| `## 위험과 대응` | 기술·자원·일정 위험과 대안 |
| `## 성과 지표` | 논문·특허·데이터·시제품의 개수와 시점 |
| `## 일정표` | 단계와 마일스톤 |
| `## 연결할 과제` | `/grant search` 에 쓸 키워드, 맞는 사업 유형 |
| `## 미확인` | 근거를 못 찾은 것, 연구자가 정할 것 |

## 지킬 것

- 자원 대조표의 "보유"는 `70-kb/assets/` 에 증빙이 있을 때만 씁니다.
- 핵심 자원이 "없음"이나 "조달 미확보"면 기획서 맨 위에 먼저 적습니다.
- 성과 지표는 보유 자원과 일정으로 설명할 수 있는 만큼만 씁니다.
