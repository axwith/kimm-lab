# 논문 기획서 기준

> `/paper` 에서 호출합니다. 기획서에는 아래 절이 모두 있어야 합니다(`check_planner.py` 가 확인).

## 필수 절

| 절 | 들어갈 것 | 확인할 것 |
|----|-----------|-----------|
| `## 가제와 핵심 기여` | 가제 3개, 기여 세 줄 | 기여가 "처음으로 ~했다"면 근거 문헌이 있는가 |
| `## 연구 질문과 가설` | 질문 1~2개, 검증 가능한 가설 | 가설이 실험으로 반증될 수 있는가 |
| `## IMRaD 골격` | 서론·방법·결과·논의 절마다 들어갈 내용 | `imrad-structure.md` 의 구성 |
| `## 그림·표 계획` | 그림·표마다 데이터와 보이려는 주장 | 주장 없는 그림이 있는가 |
| `## 필요한 실험·분석` | 보유 데이터로 되는 것 / 새로 할 것 | 새로 할 것의 자원 상태 |
| `## 분석 방법` | 쓸 도구·라이브러리·버전 | 공식 문서로 확인했는가 |
| `## 선행연구 위치` | 가까운 문헌 3~5편과 우리 연구의 차이 | cite_check 통과 문헌만 |
| `## 목표 저널·학회` | 후보 2~3곳, 범위 링크 | 지표는 확인한 값만 |
| `## 일정` | 투고 목표일에서 거꾸로 계산한 단계 | 실험 기간이 현실적인가 |
| `## 저자와 기여` | 초안 | 결정은 연구자 |
| `## 미확인` | 근거를 못 찾은 것, 연구자가 정할 것 | — |

## 금지

- 하지 않은 실험의 수치·통계 결과를 쓰지 않습니다. 기대 결과는 "가설"로 씁니다.
- 출처 없는 저널 지표(영향력 지수, 수락률, 심사 기간)를 쓰지 않습니다.
