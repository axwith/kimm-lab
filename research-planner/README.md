# Research Planner — 연구 기획 워크스페이스

지금 하고 있는 연구에서 출발해 **다음 연구 시나리오를 뽑고, 논문과 연구를 기획하는** Claude Code 워크스페이스입니다. 과제 공고 탐색과 계획서 쓰기도 기능 하나로 들어 있습니다.

## 할 수 있는 일

| 하고 싶은 일 | 명령 | 결과 |
|--------------|------|------|
| 내 연구를 정리해 두기 | `/start` | 연구 프로필, 보유 역량 표 |
| 최근 연구 동향과 선행연구 찾기 | `/lit {질문}` | 문헌표(인용 실재 확인 포함), 빈틈 목록 |
| 이 주제를 누가 필요로 하나 알아보기 | `/market {주제}` | 수요자, 시장 규모, 정책·예산, 기업·제품, 반대 신호 |
| 다음에 할 연구 방향 찾기 | `/scenario` | 시나리오 3~5개와 기준별 비교표 |
| 논문 기획 | `/paper {시나리오}` | 가제, 기여, IMRaD 골격, 그림·표 계획, 목표 저널 후보, 일정 |
| 연구 기획 | `/plan {시나리오}` | 목표, 단계, 자원 대조, 위험, 성과 지표, 일정 |
| 과제 공고 찾기와 적합도 판정 | `/grant search {키워드}`, `/grant fit {공고}` | 공고 목록, 요건표, 적합도 판정 |
| 계획서 본문 쓰기 | `/proposal` | 계획서 초안과 산술 검사 |
| 빠진 것·약점 찾기 | `/review {파일}` | 근거·방법·반론 검토표 |
| 오늘 한 일 기록 | `/wrap` | 세션 기록 |

## 시작하기

1. 이 폴더를 받습니다(`git clone` 또는 압축 파일).
2. Claude Code(데스크톱 앱, 터미널, VS Code 어디서든)로 이 폴더를 엽니다.
3. "이 폴더를 신뢰하시겠습니까" 창에서 허용합니다. 이때 gptaku-plugins 마켓과 아래 플러그인 6개가 자동으로 등록됩니다.
4. `/start` 를 입력합니다. 플러그인 확인과 연구 프로필 인터뷰가 이어집니다.

자세한 첫 30분은 [ONBOARDING.md](ONBOARDING.md)에 있습니다.

## 자동으로 켜지는 플러그인

`.claude/settings.json` 에 적혀 있습니다. 공개 저장소 github.com/fivetaku/gptaku_plugins 에서 받아옵니다.

| 플러그인 | 이 공간에서 쓰는 곳 |
|----------|---------------------|
| insane-research | `/lit`, `/market`, `/scenario` 의 공개 동향 조사 |
| insane-search | 막힌 공개 페이지 읽기, 공고 원문 |
| docs-guide | `/paper` 의 분석 도구 공식 문서 확인 |
| show-me-the-prd | `/plan` 에서 연구용 도구를 기획할 때 |
| kkirikkiri | `/review` 의 세 관점 검토 팀 |
| skillers-suda | 반복 업무를 내 명령(스킬)으로 만들 때 |

GitHub 에 접속할 수 없는 환경에서는 플러그인 없이도 모든 명령이 동작합니다(웹 검색과 직접 작성으로 대체).

## 지키는 규칙

- 근거가 없으면 "미확인"으로 남깁니다. 하지 않은 실험의 수치는 쓰지 않습니다.
- 인용은 `60-scripts/cite_check.py` 로 실재를 확인한 것만 씁니다.
- "보유"는 `70-kb/assets/` 에 증빙이 있을 때만 씁니다.
- 웹을 쓰는 플러그인과 검색에는 공개해도 되는 주제만 넣습니다. 기관 자료를 넣기 전에 소속 기관의 AI 사용 규정을 확인합니다.
- 연구 방향, 저자, 지원 여부는 연구자가 정합니다.

## 폴더

| 폴더 | 내용 |
|------|------|
| `00-inbox/` | 내 논문·보고서·메모를 넣는 곳 |
| `10-literature/` | 문헌표, 출처 |
| `15-market/` | 시장·수요 조사 |
| `20-scenarios/` | 연구 시나리오 |
| `30-papers/` | 논문 기획서 |
| `40-plans/` | 연구 기획서 |
| `50-grants/` | 공고 분석, 적합도, 계획서 |
| `60-scripts/` | 공고 수집, 인용 확인, 기획서·계획서 검사 |
| `70-kb/` | 연구 프로필, 보유 역량, 공고 판정 기록 |
| `90-log/` | 세션 기록 |
| `logs/` | 훅이 남기는 도구 사용 이력 |
| `examples/` | 연습용 가상 프로필 (자기 연구 예시, 관심 주제 예시) |

## 스크립트 (표준 라이브러리만 사용)

```bash
python3 60-scripts/check_planner.py {파일}        # 기획 문서 필수 절·증빙 검사
python3 60-scripts/cite_check.py file {파일}      # 인용 실재·철회 확인 (Crossref, OpenAlex, arXiv)
python3 60-scripts/rnd_ancm.py ntis --keyword {키워드}   # 국가 R&D 공고 검색
python3 60-scripts/check-submission.py {계획서}   # 계획서 형식·산술 검사
```
